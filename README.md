# Página de reservas de Romina Bravo

Página tipo "link in bio" para reservar planes de gestión de redes sociales.

## Cómo editar (sin saber programar)
Abre `index.html` y busca el bloque **CONFIGURACIÓN** (está casi al final, marcado con ✏️).
Ahí cambias solo el texto entre comillas: nombre, bio, precios, horarios, Instagram,
links de Mercado Pago y días bloqueados.

- **Foto:** sube una imagen cuadrada llamada `foto.jpg` a esta misma carpeta.
- **Bloquear un horario ya reservado:** en `bloqueados` agrega por ejemplo
  `"2026-11-25": ["10:00"],` o `"2026-12-24": "todo",` para el día completo.
- **Dólar:** cambia `tipoCambio` y todos los precios en USD se recalculan solos.

## Reservas por correo
Las reservas llegan a tu correo mediante FormSubmit (gratis).
La **primera vez** que alguien reserve te llegará un correo de FormSubmit pidiendo
"Activate form": haz clic una sola vez y desde ahí te llegan todas.
